# SRD LOOT AND HAZARD INDEX (SRD 5.2.1): magic items by rarity, hazards by kind

For the Universal tier (§7-bis LOOT and HAZARD PROCEDURES), which cannot run `srd.py`.
Filter by rarity (loot) or by environment and level (hazards), number what is left, and
roll it. Engine tiers use `srd.py loot` and `srd.py hazards` instead. Generated by
`tools/build_srd.py`; do not edit by hand. Environment tags on hazards are hand tags.
